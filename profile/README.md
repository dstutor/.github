Data Science Tutor shows how data science code changes data, one step at a time.
You write code in a notebook, run it, and watch each operation animate from input
to output. It all runs in your browser with Pyodide, so there is nothing to
install and no server.

Try it at [dstutor.org](https://dstutor.org).

Instructors can link straight to an example with `?example=<id>`, or embed a
read-only walkthrough in a course site with `?embed=1`. The
[repo README](https://github.com/dstutor/dstutor.github.io#readme) has the details.
